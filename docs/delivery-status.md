## 明确取舍与边界

1. 在独立副本实现并保留原工程，未删除、合并到来源或公开发布；代价是保留多份目录和归档。
2. 文件说明只读注册工作区，外部技能目录显式指定；代价是旧的隐式用户/祖先目录不会自动加载。
3. startup/shutdown 是任务边界；后台工作以持久化任务代替独立窗格进程；代价是部分 Java 界面和启动参数不逐项相同。
4. 固定原模型、逐动作审批、确定性压缩、保守工作树合并/回收；代价是不保留旧的模型覆盖、广泛审批缓存、自动清理和复杂合并行为。
5. 对话与文件回退分开，状态恢复使用新目录，不自动恢复工作区文件；代价是恢复需要额外明确步骤。
6. 路径校验与进程树控制不宣称等同于 Windows OS 沙箱；未做同权限恶意进程持续替换文件系统的对抗演练，不能承诺抗此类竞争。
7. 行为矩阵是实现/断言意图映射，不是每条 Java 原始断言语义等价的证明；发行判断按公开替代契约和实际证据，完整验收仍开放。

独立审查未执行的全量测试、构建和模型验收已由主执行流程实际运行并如上报告；审查未判断的干净 Windows 和并发恶意路径替换不能被这份报告补写成通过。
