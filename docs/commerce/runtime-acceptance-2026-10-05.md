## 发现并修复的问题

- 商品提交工具未明确 `candidate` 必须为数组，模型曾传入包含 plan/products 的对象。补充明确参数说明和空批次要求，保留一次纠错限制。
- 店长上下文缺少任务步骤准确 ID，模型曾按角色名猜错 ID。上下文返回固定工作流步骤，不扩展工具权限。
- 模型文字结束可能缺少角色产物。完成门禁增加最多两次补正；缺少结构化输出仍失败。网站开发需封存代码后提交 blueprint。
- Docker 29 的 capabilities 使用 CAP_ 前缀，未发布的镜像 EXPOSE 端口返回 null。按语义核对，仍拒绝额外权限和实际外露端口。
- 当前 Docker 内部网络的发布参数没有产生端口映射。增加可选的宿主回环预览转发，目标只能是经验证的该任务内部容器 IPv4:80；不添加外网网络。最多 32 连接、30 秒连接期限、清理关闭监听和连接；进程重启后通过独立验证重建监听，不能凭历史 READY 假定可访问。
