# 新用户使用指南（Onboarding）

> 说明：以下内容仅依据 `quickstart.md`、`security.md`、`architecture.md` 整理；每项要点都标注来源文件名。未在原文明确说明的功能不做扩展解释。

## 1. 启动与令牌

- 先执行项目根目录的 `Start-MUSE.ps1`；启动窗口会显示**本地访问令牌**，用它进入工作台。该令牌与模型 API 密钥不同。来源：`quickstart.md`
- 如需手动启动，`api` 和 `worker` 两个终端要使用**完全相同**的配置和数据目录；可用 `doctor` 做安全配置检查，`token` 可显式读取本机访问令牌。来源：`quickstart.md`
- 安全边界说明：服务仅监听 `127.0.0.1`，并校验 Host、Origin 和本地 bearer 令牌；不要将端口直接映射到公网。来源：`security.md`
- 模型密钥只在服务进程内读取原配置所引用的环境变量，不会进入设置响应、前端代码或迁移导出。来源：`security.md`
- 原配置中的环境变量必须在启动 MUSE 的进程中可用；若模型认证失败，应检查这一点。来源：`quickstart.md`

## 2. 原模型配置

- 网页工具**不使用模型代理**，模型配置本身保持不变。来源：`quickstart.md`
- 模型密钥只从原配置引用的环境变量读取，且仅在服务进程内使用。来源：`security.md`
- 任务恢复时会从持久化结果重建成果、来源、等待输入和变更记录，这不等同于修改原模型配置。来源：`architecture.md`

## 3. 网页研究限制

- 网页读取采用**静态公开文档模式**，禁用 JavaScript 和跨域跳转；如果页面会跳转，请直接提供最终页面地址。来源：`quickstart.md`
- 网页工具仅访问公开 HTTP(S) URL，拒绝私有/回环/特殊地址、凭证 URL、非 GET 请求和 WebSocket，并阻止下载。来源：`security.md`
- 浏览器不共享用户浏览器登录态，且固定连接已经校验的 IP；关闭代理、JavaScript、服务工作线程和预解析，只放行同源文档 GET。来源：`security.md`
- 因上述限制，依赖脚本渲染、登录、跳转或专用代理的网站可能无法读取。来源：`security.md`
- 网页内容会作为不可信资料传给模型。来源：`security.md`

## 4. 文件与命令权限

- 文件工具只在**注册工作区**内工作；会拒绝父目录穿越、外部绝对路径、符号链接、junction、Git/SSH/环境变量文件和应用状态目录。来源：`security.md`
- 添加一个已有文件夹后，任务就被授权使用其中的**非敏感文件**。来源：`quickstart.md`
- Shell 命令必须经过批准，且会继承受限环境变量；审批时应审阅命令的实际副作用。来源：`security.md`
- 命令执行仍具有本机用户权限；路径工具的限制不能被理解为对所有 Shell 命令的沙箱保证。来源：`security.md`
- 代码命令会停在等待批准状态，界面会显示准确命令和工作区；拒绝后模型会收到拒绝结果。来源：`quickstart.md`
- Windows 命令在挂起状态加入 Job Object 后才恢复执行；退出、超时或取消会关闭 Job 并终止受控进程树，但无法撤销已完成的网络请求或文件写入。来源：`security.md`

## 5. 暂停、取消、恢复

- **暂停**：当前模型响应/工具完成后，在安全边界停下；继续时使用已保存的结果。来源：`quickstart.md`
- **取消**：可中断模型请求、导航或受控命令；但已产生的文件/外部效果不会自动撤销。来源：`quickstart.md`
- **等待补充**：在任务输入框填写内容后继续原任务。来源：`quickstart.md`
- **已结束任务**：填写跟进目标，会创建关联的新任务并保留原结果。来源：`quickstart.md`
- **中断**：已确认的只读步骤保留；无法确定副作用的调用不会自动重放。专用文件写入可通过哈希核对，外部命令需人工检查后取消旧任务并创建新任务。来源：`quickstart.md`
- **文件回退**：只回退专用写入工具跟踪的文件；若用户后续修改导致哈希冲突，则拒绝覆盖。来源：`quickstart.md`
- 恢复时会从持久化工具结果重建成果、来源、等待输入和变更记录；客户端重连时按 sequence 继续。来源：`architecture.md`
- 工具崩溃时：只读调用退回 PREPARED；副作用调用转为 UNKNOWN，并将任务保持 INTERRUPTED。来源：`architecture.md`

## 6. 成果

- 来源位于右侧“来源”，报告位于“成果”；点击成果可下载其对应版本。来源：`quickstart.md`
- 大输出会保存为可分段读取的成果。来源：`architecture.md`
- 成果采用独立文件和数据库元数据，下载时校验 SHA256。来源：`architecture.md`
- 命令日志也是可下载成果。来源：`architecture.md`
- 保存后的成果会在任务恢复时被重建。来源：`architecture.md`

## 7. 额外提示

- 默认活动预算为 40 次模型请求、100 次工具执行、900 秒活动时间；等待审批和用户输入不计入活动时间。来源：`quickstart.md`
- 任务排队时，可检查 Worker 是否运行以及 `.muse/worker.err.log`。来源：`quickstart.md`
- 无法访问网页时，可检查 URL 是否为公开 HTTP(S) 地址，以及网络和 Chromium 安装。来源：`quickstart.md`
