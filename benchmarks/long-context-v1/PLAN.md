# Long-context component workflow pilot (preregistered)

This is a scripted production-component stress/recovery pilot, not eight hours of autonomous coding. Three independent sessions replay the same seeded synthetic history. Each session crosses approximately100K,200K,300K cumulative new-history token estimates (chars/3.5), with real production compact calls whenever shouldAutoCompact returns true at the original128K window/95K threshold. A target denotes accumulated supplied history, not simultaneously resident context or provider-billed tokens. Exact crossing values are recorded; no threshold is lowered.

Each stage introduces new task state, numeric constraints, a rejected approach with its reason, an API contract and a next step. Deterministic verbose synthetic build logs come from real read_file calls through ToolRegistry; they supply load, not a representative corpus. History is persisted through SessionWriter and loaded through SessionLoader after each compaction. ContextManager is reconstructed on the same session to verify replacement-ledger replay. One large Unicode read exercises real offload and stable reloading. Memory/home are isolated; a deliberately stale project MEMORY.md is loaded through MemoryManager, while current MEWCODE.md instructions and later user messages specify current values.

At each stage: save compact input/output/recent/recovery, diagnostics/retries, persisted and resumed context, exact active estimate and cumulative new-history estimate, real tool actions/results, provider requests/responses and elapsed time. Query the real model for structured JSON answers to all facts introduced so far plus current task state. Score each field with strict JSON type/value equality, including numbers and booleans; absent/malformed/contradictory fields fail. This is executable state retrieval, not a semantic evaluator or human review. Summary-only and complete-context probes are separate real model calls. Summary-only excludes recent/recovery/memory/instructions; complete probe uses resumed messages and actual loaded prompt context.

No summary-template change, retry tuning or success replacement. Abort the current session on compact failure; preserve errors and continue remaining prespecified sessions. No elapsed-hour extrapolation. One-session-at-a-time;3 repetitions. Internal compaction retries are retained; no harness retry. Model gpt-5.4-mini Responses, production config unchanged, no model seed set. Fixture seed20260905. Full tests gate precedes real calls.

Before this pilot, fix two separately confirmed integration bugs: cached Responses input counted twice, and recovery attachments reinjecting full tool schemas. These are not invented OLD summary templates. Earlier context-quality findings remain NEEDS_MORE_TESTING and cannot be replaced by a small structured-state pilot.
